# 可用数据集描述

## 1. 氟斑牙（Dental Fluorosis）图像数据集

### 1.1 数据概览
- **图像总数**：200 张
- **分级体系**：Dean 指数简化版（0–3 级）
  - 0 – Normal（正常）
  - 1 – Mild（轻度）
  - 2 – Moderate（中度）
  - 3 – Severe（重度）
- **每类样本数**：各 50 张，类别完全平衡。

### 1.2 图像属性
- **模态**：口腔自然光照片 
- **图像格式**：png
- **分辨率/尺寸**：512×256（宽高比 2:1，非标准方形比例，数据加载时需注意 resize/pad 策略）

### 1.3 标注信息
- **标注来源**：由临床医生根据 Dean 氟斑牙指数分级标准进行人工标注。

### 1.4 文件组织结构
dental_fluorosis/images/
├── normal/ (50 images)  
├── mild/ (50 images)  
├── moderate/ (50 images)  
└── severe/ (50 images)

## 2. 数据挑战与注意事项

1. **氟斑牙数据集样本量较小**（每类 50 张，共 200 张），需考虑数据增强、迁移学习等手段防止过拟合。
2. **标注主观性**：Dean 分级具有一定主观性，不同医生之间一致性可能低于 70%，需在实验设计中考虑此因素。
3. **类别分布**：已人为平衡，每类 50 张。

**重要说明**：当前数据集仅包含自然光（白光）口腔照片，不含荧光图像。多模态融合（白光+荧光）在本项目中属于远期探索方向，当前阶段以白光单模态分级为主要任务。
